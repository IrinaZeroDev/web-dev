# VD04-1: Flask Приложение даты и времени

Это является приложением Flask, которое отображает текущие дату и время на главной странице.

## Требования

- Python 3.7+
- Flask

## Установка

```bash
pip install flask
```

## Структура проекта

```
VD04-1/
├── app.py                 # Основное приложение
└── templates/
    └── index.html         # HTML шаблон
```

## Запуск

```bash
python app.py
```

Откройте браузер и перейдите на:

```
http://localhost:5000
```

## Функционал

- Отображение текущей даты в формате  DD.MM.YYYY
- Отображение текущего времени в формате HH:MM:SS
- Отображение полных даты и времени
- Оформленный интерфейс с градиентным фоном
