# VD04-2: Flask Многостраницные веб-приложение

Продвинутое Flask приложение с несколькими страницами, навигацией, статическими файлами и темплейтами.

## Требования

- Python 3.7+
- Flask

## Установка

```bash
pip install flask
```

## Структура проекта

```
VD04-2/
├── app.py                      # Основное приложение Flask
├── static/
│   └── style.css              # CSS стили и оформление
└── templates/
    ├── index.html          # Главная страница
    ├── blog.html           # Страница блога
    └── contacts.html       # Страница контактов
```

## Функция

Маршруты Flask:
- `/` - Главная страница
- `/blog` - Страница блога с несколькими постами
- `/contacts` - Страница контактов с формой

## Основные особенности

✅ **Навигация** - Эффективная навигация меню через Jinja2
✅ **Отмеченные меню** - На всех страницах определен активный пункт
✅ **Множества данных** - Приложение передает данные из Python в темплейты
✅ **Статические файлы** - Экстернальные CSS стили
✅ **Респонсивный дизайн** - Нормально работает на мобильных и настольных устройствах

## Запуск

```bash
python app.py
```

Откройте браузер и перейдите на: **http://localhost:5000**

## Маркировка Jinja2

Приложение использует Jinja2 для:
- Циклов для навигации: `{% for item in nav %}`
- Условных операторов: `{% if current_page == 'blog' %}`
- Вывода переменных: `{{ post.title }}, {{ contact.email }}`
