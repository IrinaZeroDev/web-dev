# VD05 - Flask Flask приложение с Наследованием Шаблонов

## Описание

Это Flask приложение, которое демонстрирует использование Jinja2 шаблонов с наследованием. Приложение состоит из трех страниц:

- **Главная** (`/`) - Страница с объяалениями переменных и основными функциями
- **О сайте** (`/about`) - Информация о проекте и технологиях

## Структура проекта

```
VD05/
├── app.py                 # Flask навигация с маршрутами
├── README.md              # Этот файл
└── templates/             # Направление по шаблонам Jinja2
    ├── base.html          # Базовый шаблон с Навигациею и CSS
    ├── home.html          # главный шаблон (наследует base.html)
    └── about.html         # О шаблоне (наследует base.html)
```

## Ключевые особенности

### 1. Наследование Шаблонов

- `base.html` рендер **base template** с Навигацией, header и footer
- `home.html` и `about.html` это *дочерние* шаблоны, которые наследуют базовый шаблон
- Они передают маршрут для `{% block title %}` и `{% block content %}` блоков

### 2. Flask Маршруты

- `GET /` - Отображает home.html
- `GET /about` - Отображает about.html

### 3. Активная Навигация

- `base.html` анализирует `request.path` для определения активного навигационного узла

## Как запустить

### 1. Мы используем Flask и Python

```bash
# установка Flask
pip install flask

# Запустить приложение
python app.py
```

### 2. Посетить url в браузере

- Главная: `http://localhost:5000/`
- О сайте: `http://localhost:5000/about`
