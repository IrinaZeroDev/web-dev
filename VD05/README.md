# VD05 - Flask Flask приложение с Наследованием Шаблонов

## Описание

То ни это основное Flask приложение, которое демонстрирует использование Jinja2 шаблонов с наследованием. Приложение состоит из трех страниц:

- **Главная** (`/`) - Страница с доброявляем и основными функциями
- **О сайте** (`/about`) - Информация о проекте и технологиях

## Структура проекта

```
VD05/
├── app.py                 # Flask аппликация с маршрутами
├── README.md              # Этот файл
└── templates/             # Направление по шаблонам Jinja2
    ├── base.html          # Базовый шаблон с Навигациею и CSS
    ├── home.html          # главные шаблон (наследует base.html)
    └── about.html         # О шаблоне (наследует base.html)
```

## Ключевые особенности

### 1. Наследование Шаблонов

- `base.html` редер **base template** с Навигациею, header и footer
- `home.html` и `about.html` **эти детские шаблоны** наследуют базовых
- Они оверрайд `{% block title %}` и `{% block content %}` блоки

### 2. Flask Маршруты

- `GET /` - Отображает home.html
- `GET /about` - Отображает about.html

### 3. Активная Навигация

- `base.html` анализирует `request.path` для определения активного навигационного пункта

## Как запустить

### 1. Мы используем Flask и Python

```bash
# Нарди с Flask
pip install flask

# Напустить приложение
python app.py
```

### 2. Посетить в браузере

- Главная: `http://localhost:5000/`
- О сайте: `http://localhost:5000/about`
