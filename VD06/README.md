# VD06 - Flask веб-приложение с формой анкеты

## Описание

Это Flask приложение реализует веб-форму для сбора данных о пользователях. Она включает:

- Форму для отправки данных (имя, город, хобби, возраст)
- Отображение введённых данных на той же странице
- Красивое оформление Bootstrap
- Накопление анкет в списке

## Структура проекта

```
VD06/
├── app.py                 # Flask приложение
├── README.md              # Этот файл
└── templates/
    └── form.html          # HTML форма с Bootstrap стилями
```

## Функциональность

### На главной странице (`/`):

1. **Форма для ввода данных**:
   - Поле имени (text)
   - Поле города (text)
   - Поле хобби (text)
   - Поле возраста (number, 1-150)
   - Кнопка отправки

2. **Отображение анкет**:
   - Отображаются все поданные анкеты
   - Каждая анкета имеет номер (#1, #2, ит.d.)
   - Данные выводятся в красивые карточки

## Основные технологии

- **Flask** - веб-рамка
- **Python** - язык программирования
- **HTML** - маркуп
- **Bootstrap** - CSS фреймворк
- **Jinja2** - мотор темплетов

## Как запустить

1. **Наименовать Flask**:
```bash
pip install flask
```

2. **Напустить приложение**:
```bash
python app.py
```

3. **Открыть в браузере**:
```
http://localhost:5000/
```

## Особенности реализации

- **POST метод** - данные сразу на странице
- **Проверка полей** - все поля обязательны
- **Стилизация** - Градиентные фоны и адаптивный дизайн
- **Нумерация анкет** - Каждая анкета получает номер
