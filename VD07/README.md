# VD07 - редактор профилей Flask

## Описание

Веб-приложение Flask с формой для редактирования профиля пользователя.

### Основные функции:

- **аутентификация**: пользователи могут регистрироваться и вохдить в систему
- **редактирование профиля**: Каждый пользователь может изменить имя, почту и пароль
- **база данных**: данные сохраняются в SQLite базе
- **хеширование паролей**: используется werkzeug.security для безопасности

## Особенности реализации

### Редактирование профиля

Основная форма редактирования:

- **Новое имя** - опционально
- **Новая почта** - опционально
- **Конфирмация текущего пароля** - обязательно для безопасности
- **Новый пароль** - опционально

## Технологии

- **Flask** - веб-рамка
- **SQLAlchemy** - ORM для работы с базами данных
- **Werkzeug Security** - хеширование паролей
- **Bootstrap** - CSS фреймворк
- **Jinja2** - генератор шаблонов
